# SaaS Launch Video

Source files, motion scenes, voice assets, and production notes for the MAIA SaaS launch video.

## Structure

- `motion_a/` - Remotion project and opening motion scenes
- `motion_b/` - Later motion scenes and render scripts
- `script/` - voice-over script
- `vo_in/` - voice-over source audio
- `work/` - timing data, visual references, and production assets

Generated build intermediates and superseded exports are excluded from version control.
